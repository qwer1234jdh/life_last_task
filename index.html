About Us

학과 소개

전자공학의 무한한 가능성으로 세상을 변화시킵니다

"전자공학은 단순한 회로 설계를 넘어, 미래 사회를 이끌어 갈 핵심 기술의 원천입니다. 우리 학과는 이론과 실습이 조화를 이루는 교육을 통해, 학생 여러분이 글로벌 무대에서 활약할 수 있는 창의적 공학인으로 성장하도록 최선을 다하겠습니다."
홍길동 교수 전자공학과 학과장

비전 (Vision)

전자·반도체·AI 분야의 글로벌 핵심 인재를 양성하는 선도적 공과대학으로 도약

미션 (Mission)

창의적 사고와 실전 역량을 겸비한 공학인 육성, 산학협력 강화, 사회 기여를 통한 지속 가능한 발전

핵심 가치

혁신(Innovation) · 융합(Convergence) · 협력(Collaboration) · 책임(Responsibility)

Why Choose Us

학과 강점

최고의 환경에서 최고의 공학인으로 성장하세요

최첨단 실험·실습

반도체 클린룸, PCB 제작실, RF 측정 장비 등 산업 현장 수준의 실험 시설 완비

높은 취업률

삼성전자, SK하이닉스, LG전자 등 국내외 주요 기업 취업률 98%, 대학원 진학률 25%

산학협력 프로그램

40개 이상 기업과 산학협력 협약, 현장 실습·인턴십·공동 R&D 프로젝트 참여 기회

자격증 취득 지원

전기기사, 정보통신기사, 반도체설계기사 등 취업 핵심 자격증 취득 전담 지도

해외 교류 프로그램

MIT, 도쿄대 등 해외 유수 대학과 교환학생 및 공동 연구 프로그램 운영

소수 정예 멘토링

교수 1인당 학생 비율 최소화, 1:1 커리어 멘토링으로 개인 맞춤형 진로 설계 지원

Curriculum

교육과정 / 전공 트랙

5개 전공 트랙에서 자신의 미래를 설계하세요

Track 01

웹 / 소프트웨어

풀스택 웹 개발부터 서버 아키텍처까지, 소프트웨어 전반을 설계하고 구현합니다. 현대 웹 기술을 기반으로 실용적인 서비스를 만드는 역량을 기릅니다.

HTML/CSS JavaScript React Node.js SQL/NoSQL

📚 핵심 과목

  • 웹 프로그래밍 기초
  • 프론트엔드 프레임워크 (React/Vue)
  • 백엔드 개발 (Node.js / Spring)
  • 데이터베이스 설계 및 관리
  • RESTful API 및 GraphQL
  • 웹 보안 및 성능 최적화

🎯 진로 분야

  • 프론트엔드 개발자
  • 백엔드 개발자
  • 풀스택 엔지니어
  • 웹 아키텍트
  • UI/UX 엔지니어
Track 02

인공지능

머신러닝과 딥러닝을 기반으로 지능형 시스템을 설계합니다. 컴퓨터 비전, 자연어 처리, 강화학습 등 최신 AI 기술을 실전에 적용하는 능력을 배양합니다.

Python TensorFlow PyTorch 컴퓨터 비전 NLP

📚 핵심 과목

  • 머신러닝 기초 및 심화
  • 딥러닝과 신경망 설계
  • 컴퓨터 비전 (OpenCV / YOLO)
  • 자연어 처리 (Transformer / BERT)
  • 강화학습 및 최적화
  • AI 모델 배포 (MLOps)

🎯 진로 분야

  • AI / ML 엔지니어
  • 딥러닝 연구원
  • 컴퓨터 비전 엔지니어
  • NLP 엔지니어
  • AI 대학원 진학
Track 03

데이터 엔지니어링

대규모 데이터를 수집·저장·처리하는 파이프라인을 구축합니다. 비즈니스 인사이트를 도출하는 분석 능력과 데이터 기반 의사결정 역량을 키웁니다.

Python SQL Apache Spark Kafka Airflow

📚 핵심 과목

  • 데이터베이스 심화 (SQL / NoSQL)
  • 빅데이터 처리 (Spark / Hadoop)
  • 데이터 파이프라인 구축
  • 스트리밍 처리 (Kafka)
  • 데이터 시각화 (Tableau / D3)
  • 데이터 웨어하우스 설계

🎯 진로 분야

  • 데이터 엔지니어
  • 데이터 분석가
  • 데이터 사이언티스트
  • BI 엔지니어
  • 데이터 아키텍트
Track 04

보안

네트워크·시스템·애플리케이션 보안을 깊이 있게 학습합니다. 사이버 위협 분석과 방어 전략을 통해 안전한 디지털 환경을 구축하는 전문가를 양성합니다.

네트워크 보안 암호학 취약점 분석 포렌식 CTF

📚 핵심 과목

  • 네트워크 보안 및 프로토콜
  • 암호학 이론과 응용
  • 웹 / 앱 취약점 분석 (OWASP)
  • 리버스 엔지니어링
  • 디지털 포렌식
  • 보안 정책 및 컴플라이언스

🎯 진로 분야

  • 보안 엔지니어
  • 침투 테스터 (Pentester)
  • 보안 분석가 (SOC)
  • 디지털 포렌식 전문가
  • 보안 컨설턴트
Track 05

클라우드 / DevOps

AWS·GCP·Azure 등 퍼블릭 클라우드와 컨테이너 기반 인프라를 설계·운영합니다. CI/CD 자동화로 빠르고 안정적인 소프트웨어 배포 체계를 구축합니다.

AWS / GCP Docker Kubernetes Terraform CI/CD

📚 핵심 과목

  • 클라우드 컴퓨팅 기초 (AWS)
  • 컨테이너 기술 (Docker / K8s)
  • 인프라 자동화 (Terraform / Ansible)
  • CI/CD 파이프라인 설계
  • 마이크로서비스 아키텍처
  • Site Reliability Engineering

🎯 진로 분야

  • 클라우드 엔지니어
  • DevOps / SRE 엔지니어
  • 인프라 아키텍트
  • 플랫폼 엔지니어
  • MLOps 엔지니어
